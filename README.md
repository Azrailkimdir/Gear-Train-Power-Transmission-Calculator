# Gear Train & Power Transmission Calculator ⚙️

A Python-based mechanical engineering project that analyzes gear systems and power transmission using fundamental engineering principles.

## Project Objective

The purpose of this project is to explore how gear ratios influence rotational speed, torque, and power transmission in mechanical systems.

## Fundamental Equations

### Gear Ratio

Gear Ratio = Number of Teeth (Driven Gear) / Number of Teeth (Driver Gear)

### Output Speed

Output RPM = Input RPM / Gear Ratio

### Output Torque

Output Torque = Input Torque × Gear Ratio

These equations form the foundation of mechanical power transmission systems and are used throughout this project.

## Why This Matters

Gear systems are used in automobiles, aircraft, industrial machines, robotics, and countless mechanical systems.

Understanding how gear ratios influence speed and torque is essential for mechanical design, power transmission, and engineering optimization.

## Research Question

How do different gear ratios affect output speed and torque in mechanical power transmission systems?

## Results

The calculator successfully evaluates gear ratios and predicts changes in rotational speed and torque.

Example:

- Driver Gear Teeth: 20
- Driven Gear Teeth: 60
- Input Speed: 1500 RPM
- Input Torque: 100 Nm

Results:

✅ Gear Ratio = 3:1

✅ Output Speed = 500 RPM

✅ Output Torque = 300 Nm

The analysis demonstrates the trade-off between rotational speed and torque in mechanical transmission systems.

Engineering Interpretation:

✅ The gear train increases torque while reducing rotational speed, providing mechanical advantage.

The results confirm the fundamental trade-off between torque and rotational speed. As gear ratio increases, torque increases proportionally while rotational speed decreases.

## Engineering Insights

The analysis demonstrates that increasing the gear ratio reduces rotational speed while increasing torque.

This trade-off is fundamental to mechanical design and allows engineers to optimize systems for different applications, from high-speed machinery to high-torque power transmission systems.

The project also illustrates how mathematical models can be implemented in software to support engineering calculations and decision-making.
